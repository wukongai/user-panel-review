# 证据策略

## 断言梯度

保持四个层级彼此分离：

1. **源观察**：评审快照中的精确行和引语。
2. **合成 Persona 反应**：以声明的 Persona 为条件、由模型生成的反应。
3. **面板模式**：worker 之间重复或冲突的合成反应。
4. **真实用户证据**：访谈、观察到的行为、分析数据、实验或销售结果。

1-3 级不会因面板规模而变成第 4 级。一千个同模型 Agent 仍然只是合成证据。

## 允许的措辞

- “四个合成 Persona worker 中有三个提出了这一摩擦点。”
- “该面板产生了强烈的合成相关性信号。”
- “这是一个需要真实读者验证的假设。”

## 没有真实数据时禁止的措辞

- “CTR 将提高 20%。”
- “80% 的用户会读完文章。”
- “这证明目标市场想要该产品。”
- “四位独立用户达成了一致。”

## 可追溯性

每个重要综合断言都必须包含 worker 结果 ID。每个引用的文章断言都必须能解析到不可变快照。报告缺失的 worker、抽样覆盖范围、模型同质性、Persona 来源和置信度限制。

在 baseline、holdout、真实 rollout 和独立评审支持更强断言前，将 `utility_claim: not-evaluated` 保持不变。

## 适配器标签

文章适配器完成确定性与用户模拟回归，可标记 `validated-mainline`，但仍只是合成证据。纯文本广告只标记 `experimental-adapter`，用于验证稳定 Persona 能在不同刺激物中复用；它不代表落地页、真实投放或转化效果获得支持。
