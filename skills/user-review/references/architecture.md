# 架构：画像库、内容映射与单次评审团

`user-review` 是用户焦点小组评审编排器，只处理目标用户视角。

```text
长期画像库 ─┐
             ├─ 内容映射 ─> 单次评审团 ─> 隔离 Persona Worker ─> 汇总报告
本次临时画像 ┘
```

## 长期画像库

保存可跨文章复用的 Persona。画像由内容关系、知识阶段、阅读场景、用户任务、痛点、信任和拒绝信号组成。画像可以新增、修改或停用，但已开始的运行不随之变化。

## 内容映射

`audience-maps.json` 建立内容线与候选 Persona 的多对多关系。选择结果必须解释“为什么这个人进入评审团”，不能只给一个不透明分数。

## 单次评审团

运行开始前固化文章和 Persona 快照。临时画像只写入运行目录，默认不进入长期画像库。每个 Persona 在隔离上下文中阅读相同文章，避免相互影响。

## 写入边界

长期保存画像必须经过 `persona-plan` 预览和同一计划哈希的 `persona-apply`。Worker 只能写自己的结果；汇总器只读已校验结果。
