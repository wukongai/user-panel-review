# 焦点小组汇总规则

## 法定人数

全部 Worker 成功为 `completed`；有失败但有效结果达到 quorum 为 `partial`；未达到 quorum 为 `failed`。失败不能被静默忽略。

## 信息分层

- 共识：多个 Persona 独立出现且有原文证据；
- 分歧：不同用户任务或知识阶段导致相反反应；
- 少数意见：只有一个 Persona 提出但可能暴露重要盲点；
- 战略性非目标拒绝：合理地不服务某类用户，不把它误写成文章缺陷；
- 应保留：修改时不能丢失的有效内容；
- 真人验证假设：需要后续访谈、可用性测试或发布数据验证的问题。

每条综合判断保存对应 `worker_result_ids`。汇总不做简单多数投票，也不把同一模型的多个 Persona 当成独立真人样本。

## 默认对外展示

普通用户无需指定报告格式。默认使用以下五个标题：

1. `共同反馈`：多类用户都出现的理解、感受或障碍；
2. `不同意见`：因任务、阶段或处境不同而产生的分歧；
3. `值得保留`：修改内容时不应丢失的有效部分；
4. `最需要修改`：综合影响与证据后最值得优先处理的问题；
5. `需要真人验证`：模拟无法证明、需要真人或真实行为继续验证的假设。

少数但重要的提醒放入最相关的栏目，并明确它只来自哪一类模拟用户。只有用户明确要求其他格式时，才改变对外标题；底层信息分层保持不变。
