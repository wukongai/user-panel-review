# 创建自己的 Audience Workspace

## 两个入口

1. **体验示范**：直接使用公共只读 Workspace，不创建私人数据。
2. **创建我的用户空间**：通过对话生成 Workspace 候选，Preview 后才 Apply。

## 对话式创建

一次只询问一个会改变分层的问题，最多围绕五类信息：

1. 你提供什么内容、产品或服务；
2. 主要帮助谁完成什么任务；
3. 用户处于哪些认知、采用或决策阶段；
4. 使用者、购买者和批准者是否为不同角色；
5. 什么建立信任，什么导致拒绝。

优先生成 3～5 个差异明确的 Persona。不要为了凑数量拆分相近用户，也不要从人口属性或敏感身份开始。

## 预览必须展示

- Workspace ID、名称、目标受众承诺和私人保存路径；
- Segment 的分层依据与未知项；
- 每个 Persona 的任务、阶段、痛点、信任/拒绝信号；
- 来源默认 `operator_hypothesis`、置信度 `low`、验证状态 `unvalidated`；
- 默认 Panel 和必要的场景 Panel；
- 将要创建的文件、计划哈希和 Apply 命令。

用户可以修改候选。只有明确确认同一计划后才创建 Workspace。私人数据默认位于 `~/.user-review/workspaces/<workspace-id>/`；不要复制 Skill，不要把私人画像写进公开仓库。

## 后续维护

评审完成后，可以提出“画像可能过粗”“拒绝信号需要补充”等学习建议，但不得自动更新。用户要求变更时，重新进入 Preview / Apply。建议定期备份整个 Workspace；Skill 升级或重装不应删除它。
