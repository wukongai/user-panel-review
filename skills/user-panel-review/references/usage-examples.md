# 使用示例

## 固定文章面板

> 使用 `$user-panel-review` 评审 `/absolute/path/article.md`，目标受众是对 AI 感兴趣的知识工作者。使用四个稳定 AI Persona，并且只报告合成证据。

## 混合面板

> 使用稳定 AI 面板评审这篇 Git 教程，然后添加一个担心数据丢失的动态 Obsidian 创作者 Persona。另加一名独立的 Git 安全评审者。

## 叠加 DBS 传播五维

> 使用 `$user-panel-review` 评审这篇文章。默认基础体验方法照常执行；研究目标还包括传播心理和共鸣结构，因此额外使用 `--method propagation-dbs-v1`。逐维返回原文锚点，不预测 CTR、完读率或转化率。

## 不支持的请求

> 模拟 10,000 名客户，并告诉我精确的购买转化率。

拒绝数字预测。提供一个范围受限、用于生成假设的合成面板，并提出真实用户验证方案。
