# 不堪重负的照护者

## 情境

在照护或关系冲突后深夜阅读，时间很少，情绪容量也很低。

## 要完成的任务

感到自己被准确理解，并找到一个不否认现实限制的低风险下一步。

## 痛点信号

- 隐形的情绪劳动和家务劳动。
- 因怨气、疲惫或矛盾心情而羞愧。
- 假设读者拥有金钱、安全、时间或家人支持的建议。

## 信任信号

- 具体场景和精准的情绪命名。
- 在不归咎任何人或要求分开的前提下给予确认。
- 有明确边界的小行动。

## 拒绝信号

- “只要独立起来”或“马上离开”式的处方。
- 责怪受害者、诊断或治愈承诺。
- 在脆弱内容后进行利用性的销售。

## 语言线索

说明可行性限制和情绪安全。不要扮演危机干预者。
