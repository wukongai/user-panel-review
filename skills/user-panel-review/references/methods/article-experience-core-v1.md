# 基础文章体验方法包 v1

状态：`candidate`

对象：Markdown 文章

方法 ID：`article-experience-core-v1`

## 用途

从目标 Persona 的处境检查文章是否容易进入、理解、信任和继续阅读，并明确哪些优势不应在改稿中丢失。

## 六个维度

1. **开头相关性**：开头是否让目标读者迅速确认“这与我有关”。
2. **任务匹配**：文章是否回应 Persona 当前真正想完成的任务。
3. **理解路径**：概念、论证和结构是否能被该 Persona 跟上。
4. **信任摩擦**：哪些说法因缺证据、缺边界或过度承诺而降低可信度。
5. **继续或拒绝**：什么具体文字使 Persona 继续、收藏、分享、关注或拒绝。
6. **应保留优势**：哪些原文内容有效，修改时不得被多数意见抹去。

## 输出要求

每个维度返回 `effective`、`weak` 或 `absent`，并绑定逐字原文锚点。判断是合成 Persona 信号，不是真人行为证据。

## 禁止

不得预测 CTR、完读率、购买率或转化率；不得把同模型 Persona 称为彼此独立的真人样本。
