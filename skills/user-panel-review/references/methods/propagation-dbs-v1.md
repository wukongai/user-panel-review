# DBS 传播五维方法包 v1

状态：`candidate`

对象：Markdown 文章

方法 ID：`propagation-dbs-v1`

## 用途与来源

当研究目标明确包含“传播心理、共鸣、是否打中目标受众或分享动机”时启用。本方法整理自 `dbs-resonate` 与 `dbs-spread` 的五维框架；它是理论型操作方法，不是平台效果预测模型。

## 五个维度

1. **沉默解除（沉默的螺旋）**：文章是否说出了受众不敢公开表达的判断或情绪。
2. **满足动机（使用与满足理论）**：文章满足身份认同、情绪宣泄、社交资本或信息价值中的什么需求。
3. **立场框架（框架理论）**：文章站在谁一边，为什么这个立场降低防御感。
4. **传播入口（两级传播理论）**：谁可能成为第一批主动分享者，其具体动机是什么。
5. **信念结构（认知一致性理论）**：文章确认了受众什么既有信念，又挑战了什么具体行为。

## 输出要求

每个维度必须返回：方法和版本、维度 ID、`effective` / `weak` / `absent`、逐字原文锚点、理论依据、具体观察和 `synthetic` 证据等级。

## 边界

- 不评价平台算法表现，不预测会不会火。
- 不输出 CTR、完读率、点击率、推荐量、购买率、转化率或未经测量的百分比。
- “传播入口”只描述待真人验证的分享者假设，不等于真实传播路径。
- 单次运行不得修改、晋升或覆盖本方法包。
