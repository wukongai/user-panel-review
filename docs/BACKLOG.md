# user-review Backlog

本文件只记录尚未承诺进入当前版本的候选。已经交付的 `user-review 2.0` 不继续挂在 Backlog；当前完成事实见 `docs/TASK.md`、`CHANGELOG.md` 与当日日志。

## 候选方向

### P1：用真实证据校准长期目标用户

- 支持用户把访谈摘要、评论、历史反馈或行为观察作为画像来源证据；
- 明确区分用户提供的事实、操作者假设和 AI 推断；
- 不保存完整私人访谈或敏感原始数据到公开 Skill 仓库。

进入当前版本前，必须先确定最小脱敏输入契约和真实回归用例。

### P1：用第二种刺激物验证通用底座

- 从广告文案、落地页文本、产品概念或课程定位中只选择一种作为第二适配器；
- 完成真实回归前继续只正式声明支持文章；
- 交互式可用性、原始 PRD、真实转化和学习效果仍不属于本 Skill。

### P2：长期目标用户的导入、导出与备份体验

- 为普通用户提供自然语言备份、恢复和迁移入口；
- 保持私人数据位于 Skill 安装目录之外；
- 所有恢复操作继续遵守预览、确认、写入和回滚边界。

## 独立产品，不进入本 Backlog

- Expert Review / Content Review 由独立 Skill 和独立仓库负责；
- 专业方法、理论量表、事实核查、合规和 DBS 传播方法层不并回 `user-review`；
- 总评审入口未来可以编排 User Review 与 Expert Review，但不改变两个 Skill 的独立边界。
