# 方法论与证据边界

## 五层结构

1. Persona：谁在看、处境和关注点；
2. Methods：按什么知识框架检查；
3. Protocol：Worker 如何隔离执行、锚定和返回；
4. Evidence：结论最多能说到什么程度；
5. Aggregation：共识、分歧、少数意见和专业风险如何合并。

## 基础文章体验方法

默认方法包含开头相关性、任务匹配、理解路径、信任摩擦、继续或拒绝、应保留优势六个维度。它来自 v0.1 已验证协议的显式拆分。

## DBS 传播五维

- 沉默解除：是否说出了受众不敢公开表达的情绪或判断；
- 满足动机：满足身份认同、情绪宣泄、社交资本或信息价值中的什么需求；
- 立场框架：站在谁一边，为什么降低受众防御；
- 传播入口：谁可能率先分享，动机是什么；
- 信念结构：确认了什么信念，又挑战了什么具体行为。

五维判断必须绑定逐字原文锚点。传播入口是待验证的分享者假设，不是真实传播路径。

## 可以声明什么

可以声明结构合规、运行可复现、结果可追溯，以及合成 Persona 提出了哪些假设。

不能声明真实用户已证明某一结论，也不能从合成结果推导 CTR、完读率、点击率、推荐量、购买率或转化率。
