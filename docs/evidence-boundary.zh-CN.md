# 模拟焦点小组的证据边界

`user-review` 生成的是 AI Persona 模拟反馈。它适合在发布前发现理解摩擦、定位冲突、信任触发和少数用户视角，但不能证明真实用户一定会如何行动。

## 可以支持的判断

- 某句话对某个已定义 Persona 是否难懂；
- 不同用户任务为何导致不同反应；
- 哪些内容值得保留；
- 下一轮真人访谈或可用性测试应该验证什么。

## 不能支持的判断

- 真实人群中的比例；
- 平台点击、阅读或购买结果；
- 真实焦点小组已经达成共识；
- 对任何群体的敏感身份推断；
- 医学、心理、法律或其他专业结论。

同一模型扮演的多个 Persona 也不能当作统计独立的真人样本。报告必须保留 Persona 来源、置信度、文章哈希、原文锚点和运行限制。
