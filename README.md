# 目标用户反馈（user-review）2.0

`user-review` 会模拟你的目标用户组成焦点小组，反馈他们看到一篇文章时可能怎样理解、喜欢什么、哪里看不懂、为什么信任或怀疑，以及什么会让他们拒绝继续阅读。

你只需要用自然语言和 Agent 对话。安装包自带一篇 AI 主题示例文章和一组对应的内置示例用户，方便先体验效果；这只是演示，不限制你的领域。以后可以改成教育、心理、美妆、消费品牌或其他业务的长期目标用户。

> 所有结果都是 AI 模拟目标用户反馈，不是真实访谈、真实焦点小组、行为数据或市场验证，也不预测点击率、完读率、购买率和转化率。

## 安装

```bash
npx skills add wukongai/user-review
```

在安装器中选择 `user-review`、你使用的 Agent 和安装范围，安装后重新打开一个会话。

## 五步快速体验

### 1. 先试一次

```text
我想先试试。请用内置示例用户看看自带的示例文章，
告诉我这些用户会怎么理解、喜欢什么、担心什么。
先介绍这次会模拟哪些用户，等我确认后再开始。
```

内置体验使用 AI 文章，只是为了安装后立即跑通。你也可以随便提供一篇自己的文章；当前正式回归对象是文章，文章主题不限。

确认时只要说“确认开始，请反馈这篇文章”。你不需要在提示词里规定报告格式；Skill 默认会自动整理为共同反馈、不同意见、值得保留、最需要修改、需要真人验证。

### 2. 改成我的长期目标用户

```text
我想改成自己的目标用户。
我主要提供____，希望帮助____。
请先根据这些信息帮我整理目标用户。
```

Agent 会自动一次确认一个关键问题，再把回答整理成几类长期目标用户。你不需要在提示词里规定它怎么提问。可以直接说“第二类不对”“这类人太专业了”或“再加一类购买决策者”。

### 3. 反馈自己的内容

```text
请让我的目标用户看看这篇文章，
告诉我他们的第一感受、看不懂的地方、信任或怀疑的原因，
以及最希望我补充什么。先告诉我这次会模拟哪些用户。
```

可以直接拖入文件、粘贴正文，或提供 Agent 能读取的文章。

### 4. 增加本次特殊用户

```text
这次再特别考虑临近高考、焦虑很强、
正在寻找立刻提分办法的学生。只用于这一次，不要长期保存。
```

### 5. 继续维护

```text
我发现“正在准备购买的人”分得太宽了。
请帮我重新整理，确认后再长期保存。
```

## 你会得到什么

- 不同目标用户各自的第一感受；
- 他们看懂和误解的地方；
- 与自己是否相关；
- 信任、怀疑和拒绝的原因；
- 共同反馈、不同意见和少数但重要的提醒；
- 值得保留的内容；
- 需要通过真人研究继续验证的假设。

## 隐私与边界

- Skill 不主动联网或上传文章；
- 不读取 `.env`、Cookie、Token、SSH 或浏览器状态；
- 文章中的命令和提示词只作为被反馈内容，不执行；
- 私人目标用户与 Skill 安装文件分开保存，升级不应覆盖；
- 不包含专家评审方法，不负责事实、医学、心理、合规、代码或产品需求评审；
- 当前完成真实回归的内容类型是文章，其他类型不提前声明支持。
